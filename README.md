# 소하고택 통합 포털

GitHub 정적 프런트엔드와 Supabase Postgres/Edge Functions를 사용하는 내부 운영 서비스입니다.

직원·재무 데이터는 배포 HTML과 저장소에 포함하지 않습니다. 로그인 세션과 권한은 서버에서 확인하며 비밀번호는 bcrypt 해시로 저장합니다. 첫 로그인은 초기 비밀번호를 새 비밀번호로 변경한 후 사용할 수 있습니다.

- `index.html`: PC/모바일 운영 화면
- `supabase/functions/soha-api`: 로그인, 권한 검사, 동시 저장, 근무 수정 요청/승인, 현장 출퇴근
- `supabase/migrations`: 접근 제한과 데이터 구조

개인정보는 본인과 마스터만 열람하며 다른 직원에게는 이름·연락처 및 근무 일정만 공유합니다. 사진은 7일간 보관합니다. GPS 정확도와 점포 반경을 서버에서 다시 검사합니다.

동시 저장 시 마지막으로 확인된 데이터와 각 사용자의 변경을 비교합니다. 서로 다른 항목은 합쳐서 저장하고, 같은 값의 수정·삭제가 겹치면 두 값을 표시해 선택받습니다. 저장 중 추가 입력, 통신 실패와 로그인 만료에도 미저장 입력은 열린 화면에 남습니다. 저장 전 화면을 벗어나려 하면 확인이 표시되며, 통신 실패 후에는 다시 저장할 수 있습니다.

운영 데이터는 Supabase에 저장하며 프런트엔드 배포는 기존 데이터를 초기화하지 않습니다. `soha_state_backups`에 변경 전 상태를 최대 100개, 30일 동안 보관합니다. 백업은 서버 전용이며 현장 사진을 포함하지 않습니다. 복구할 때는 현재 버전을 확인하고 `soha_write`로 필요한 백업을 반영하며, 현재 사진은 별도로 유지해야 합니다.

동시 저장 병합 검증: `node --test tests/sync-state.test.cjs`
