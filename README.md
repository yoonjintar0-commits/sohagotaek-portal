# 소하고택 통합 포털

GitHub 정적 프런트엔드와 Supabase Postgres/Edge Functions를 사용하는 내부 운영 서비스입니다.

직원·재무 데이터는 배포 HTML과 저장소에 포함하지 않습니다. 로그인 세션과 권한은 서버에서 확인하며 비밀번호는 bcrypt 해시로 저장합니다. 첫 로그인은 초기 비밀번호를 새 비밀번호로 변경한 후 사용할 수 있습니다.

- `index.html`: PC/모바일 운영 화면
- `supabase/functions/soha-api`: 로그인, 권한 검사, 동시 저장, 근무 수정 요청/승인, 현장 출퇴근
- `supabase/migrations`: 접근 제한과 데이터 구조

개인정보는 본인과 마스터만 열람하며 다른 직원에게는 이름·연락처 및 근무 일정만 공유합니다. 사진은 7일간 보관합니다. GPS 정확도와 점포 반경을 서버에서 다시 검사합니다.
