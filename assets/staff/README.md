## Generation prompt set

The first photograph (김보미) established the style; subsequent calls used each
employee's own photograph as identity reference and the first clay avatar only
as a style, lighting and composition reference. One asset was generated per call.

Shared specification: “One square employee avatar for the existing cafe
operations portal. Transform only the adult woman in the identity photograph
into a premium 3D handmade clay/stop-motion miniature head-and-shoulders portrait.
Preserve recognizable facial proportions, eyes, lips, hairstyle, expression and
clothing. Sculpted matte polymer clay, softly rounded forms, delicate clay
texture and sculpted hair. Straight-on centered portrait, complete hair and
shoulders, generous transparent margins for safe circular cropping. Soft studio
light. Genuine transparent background. No scene, text, watermark, frame, apron,
props or extra person. Never copy the style-reference person's identity.”

  closed-mouth smile, cream collared blouse.

  earrings, white T-shirt.
